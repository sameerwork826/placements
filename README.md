# Placements Preparation Repository

A comprehensive, organized collection of resources for analyst / data science campus placements — covering aptitude, technical skills, ML theory, case interviews, product management, and company-specific prep.

> Large files (PDFs, images, Excel) are stored via **Git LFS**. After cloning, run `git lfs pull` to download all binary files.
